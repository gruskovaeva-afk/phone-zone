PHONE ZONE — демонстраційний сайт

Як відкрити:
1. Розпакуй архів.
2. Відкрий index.html у браузері.

Як завантажити на GitHub Pages:
1. Створи репозиторій на GitHub.
2. Завантаж УСІ 4 файли: index.html, catalog.html, style.css, script.js.
3. У Settings → Pages вибери Deploy from a branch, гілку main і папку /(root).
4. Збережи. Через кілька хвилин сайт буде доступний за посиланням GitHub Pages.

Функції: пошук, категорії, виробники, ціна, сортування, кошик із кількістю та підрахунком суми.
Кошик зберігається у localStorage цього браузера. Оформлення замовлень і оплати немає.
Зображення товарів завантажуються з інтернету, тому для них потрібне підключення.
